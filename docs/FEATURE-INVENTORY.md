# Desktop features

- Local administrator and employee accounts with dashboard permissions.
- AMOS, AOG, FAK, Marshaling, and Security Permits dashboards.
- Authoritative project Excel files, imported automatically at cold start.
- Manual XLSX/XLSM uploads and keyboard date filtering.
- Local PNG exports for PowerPoint with all four dashboard layouts.
- Persistent SQLite database and filesystem storage beside the app.
- Native Electron window, branded icons, menus and file-save dialogs.
- No hosted services are required to build or run the installed app.
